# AVISOS_one_to_many

Aplicación desarrollada con Spring Boot para gestionar avisos y usuarios mediante una relación *One-to-Many* utilizando JPA y Hibernate.  
El proyecto permite comprender cómo modelar asociaciones entre entidades y gestionar la persistencia de datos en aplicaciones Java.

## Tecnologías utilizadas

- Java
- Spring Boot
- Spring Data JPA
- Hibernate
- MySQL
- Maven

## Funcionalidades

- Crear y gestionar usuarios
- Publicar avisos asociados a un usuario
- Implementación de relaciones One-to-Many
- Persistencia de datos con JPA/Hibernate
- Operaciones CRUD básicas

## Objetivo del proyecto

Practicar el uso de relaciones *One-to-Many* en aplicaciones Java con Spring Boot, aplicando conceptos de modelado de entidades, persistencia y arquitectura MVC.
